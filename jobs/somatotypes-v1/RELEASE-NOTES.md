# Somatotypes TikTok edit · v1.0.0

Finished exports for the somatotypes explainer, rendered from the creator's Taglish recording.

## Files

- `somatotypes-tiktok-v1-1080p-upload.mp4` — native 1080 × 1920, 60 fps TikTok upload copy.
- `somatotypes-tiktok-v1-4k-master.mp4` — 2160 × 3840, 60 fps archive upscale from the 1080p presenter source.
- `somatotypes-tiktok-v1-cover.png` — separate portrait cover still from frame zero.

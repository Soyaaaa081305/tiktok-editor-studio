## Permanent visual grammar

1. **Two layers with different jobs.** Most explanation passages show the current subject in the upper roughly 35–50% and a continuing, closely framed presenter below. The top insert can change while the presenter remains continuous. It is not a tiny floating stock-video rectangle.
2. **Spoken words choose the picture.** Named places, objects and animals cause literal insert changes. A rapid list produces a quick sequence of subject-matched upper shots; a longer explanation gets a longer useful hold.
3. **Camera resets.** Full-screen presenter moments create turns between passages. Full-screen source inserts emphasize genuinely important evidence or examples. Use these as rest beats, not constant escalation.
4. **Editorial cuts dominate.** The reference mainly changes upper footage with direct cuts. Preserve that clarity. For new work use a small, repeatable set of motivated mask/match/whip transitions, with short SFX; do not turn every cut into a sweeping effect.
5. **Big numbers get a real role.** Large mass/depth figures are given clear prominence over relevant imagery. New projects may use a number only when its exact value, unit, denominator and source are verified; decorative progress bars must never pretend to be evidence.
6. **Evidence stays identifiable.** Maps, quoted-source panels, project structure/timeline graphics and highlighted text appear as evidence-oriented upper/full-screen inserts. Add a readable source label and enough hold time. Do not create fake articles or study screenshots.
7. **Escalation has visual variety.** Genuine upper B-roll, location graphics, numerical emphasis, evidence highlights, presenter resets and occasional full-screen examples keep the visual idea changing. Avoid a deck of similarly shaped text cards.
8. **No slow intro.** The reference starts with the main tension. Our user-required real-photo 0.4-second poster is an additional rule, followed immediately by the strongest source hook; omit the reference's final TikTok platform outro.

## Broad script architecture, independently written

Concrete tension → identify the person/topic → explain the plan or mechanism → escalate with useful examples → reveal a larger implication → support with an identifiable source → concise ending. This is a generic information structure. For product/education videos, adapt it to a truthful problem → ingredient/feature explanation → verified product detail → personal experience when actually supplied → one CTA. Never import the expedition's danger framing into a supplement promise.

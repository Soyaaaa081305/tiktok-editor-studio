# Production workflow

This is the user's private, portable TikTok production project. Read
`README.md` and inspect the current files before working. Use the saved prompts:

- For a topic or a new script, apply `prompts/03-topic-to-script-prompt.md`.
- For a recording to edit, apply `prompts/04-master-production-system-prompt.md`.
- Use `prompts/house-style.json` and the cached reference record for consistency.
- The latest direct user instruction takes precedence over these defaults.

Save each new recording's exact edit blueprint, execution prompt, edit plan,
captions and sound cues. Use deterministic frame-based Remotion animation.
Prefer real footage and meaningful visuals; connect changes to the spoken
words. Preserve the user's original natural dialogue. Do not fabricate studies,
figure values, product facts or testimonials. Read accessible primary sources;
record limitations when an article or Patreon post cannot be accessed.

New work uses lighter phrase captions and selective large keywords, the useful
upper-image/lower-presenter layout, approximately 0.1s genuine opening cover,
audible purposeful SFX and no added music unless requested. The older finished
snapshots remain reproduction references; they do not override these defaults.

Start Studio from the project root so `remotion.config.ts` is loaded. Reuse
the installed local components and selected media. Restore missing files with
`pnpm assets:restore`. Keep versions locked; do not copy OS-specific dependency
folders between computers. Write outputs inside this project's `outputs/`.
Do not commit credentials, unrelated personal files, caches or large media.
Do not publish a repository or release publicly without direct authorization.

When the user requests an edit and export, finish the authorized work and
inspect the actual exported video/audio. Report what was checked and what was
not checked. Never claim 100/100, a full reference watch, a licensed asset,
continuous playback or a Mac verification without supporting evidence.
